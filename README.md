# GoalFusion

Landing page for **GoalFusion** — a lifestyle complex on Namanga Road, Kitengela, housing three distinct brands under one roof.

## Brands

- **[GoalHub](https://www.goalhub.ke/)** — Professional-grade football turfs for the beautiful game.
- **[KienyejiHub](https://www.kienyejihub.ke/)** — Heritage African dining where the soul of cuisine meets the rhythm of sport.
- **[ExpressCarpets](https://www.expresscarpets.co.ke/)** — Artisan-crafted luxury flooring and bespoke interiors.

## Tech Stack

- HTML5 + [Tailwind CSS](https://tailwindcss.com/) (CDN)
- [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque) typeface
- Deployed via GitHub Actions to **GitHub Pages**

## Development

The site is a single `index.html` file — no build step required. Open it directly in a browser or serve it locally:

```bash
npx serve .
```

## Deployment

Pushing to `main` (or the feature branch) triggers the GitHub Actions workflow at `.github/workflows/deploy.yml`, which publishes the site to GitHub Pages automatically.
